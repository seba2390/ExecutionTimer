# Security Policy

## Supported versions

Only the latest released version of `executiontimer` receives fixes.

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/seba2390/ExecutionTimer/security/advisories/new)
rather than opening a public issue.

Expect an initial response within 7 days. If the report is confirmed, a fix and an
advisory will be published together.
